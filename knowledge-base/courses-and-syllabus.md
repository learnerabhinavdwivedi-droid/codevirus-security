# Codevirus Academy — Courses, Syllabus & Training Programs
**Campus**: Kapoorthala, Aliganj, Lucknow, UP, India  
**Modes**: 100% Practical In-Person Labs (Lucknow Campus) & Interactive Live Online Batches  

---

## 1. Certified SOC Analyst Program (Security Operations Center)
- **Target Role**: Tier-1 / Tier-2 SOC Analyst, Incident Responder, SIEM Engineer
- **Duration**: 6 Months (Specialist Track) / 1 Year (Comprehensive Cyber Defense Diploma)
- **Key Modules**:
  - Networking fundamentals, TCP/IP deep-dive, Packet Analysis (Wireshark)
  - Linux & Windows enterprise system internals, audit logs, Event IDs
  - SIEM Deployment & Analysis: Splunk Enterprise, Wazuh Open Source SIEM
  - Attack Detection, Log Parsing, Alert Triage, Rule Writing (YARA, Sigma)
  - Endpoint Detection & Response (EDR), Live Memory & Disk Forensics
  - Real-time Attack–Defense blue team simulations in dedicated cyber ranges
- **Eligibility**: Open to B.Tech, BCA, MCA, BSc IT, and career switchers (networking taught from ground zero).
- **Prerequisites**: No prior coding experience required; basic computer familiarity.

---

## 2. VAPT & Bug Bounty Mastery (Offensive Security)
- **Target Role**: Penetration Tester, Vulnerability Researcher, Security Consultant
- **Duration**: 6 Months (Hands-On Intensive)
- **Key Modules**:
  - Web Application Architecture, HTTP/HTTPS protocol mechanics
  - Burp Suite Professional: Interception, Intruder, Repeater, Automations
  - OWASP Top 10 (2021/2025): SQLi, XSS, SSRF, CSRF, IDOR, Broken Authentication, RCE
  - API Pentesting: REST & GraphQL security, Postman testing
  - Android & Mobile App Pentesting: APK decompilation, MobSF, Frida dynamic analysis
  - Bug Bounty Methodology: Reconnaissance, Subdomain discovery, Live responsible disclosures
- **Certifications Supported**: CEH Practical, eJPT, OSCP roadmap.

---

## 3. Network & Cloud Security (CCNA & AWS Cloud Defense)
- **Target Role**: Network Security Engineer, Cloud Security Administrator
- **Duration**: 3 to 6 Months
- **Key Modules**:
  - Routing, Switching, VLANs, Subnetting, IPv4/IPv6, ACLs, NAT/PAT
  - Enterprise Firewall deployment (pfSense, FortiGate basics)
  - AWS Cloud Fundamentals: IAM policies, VPC peering, Security Groups, S3 hardening, CloudTrail
  - Linux Systems Administration & Hardening for Cyber Defenders

---

## 4. Digital Forensics & Incident Response (DFIR)
- **Duration**: 3 Months (Advanced Module)
- **Key Modules**:
  - Evidence acquisition, Chain of Custody, Write-blockers
  - Windows artifact analysis (Prefetch, Amcache, Registry, Shimcache)
  - Memory analysis using Volatility framework
  - Malware behavior analysis in isolated sandbox environments
