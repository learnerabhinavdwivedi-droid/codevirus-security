## 1. Vulnerability Assessment & Penetration Testing (VAPT) Scope

### A. Web Application Security Assessment
- OWASP Top 10 Comprehensive Blackbox / Graybox / Whitebox testing
- Business Logic Flaw identification, Privilege Escalation, Payment Gateway tamper testing
- Session Management, Token analysis, Cryptographic verification
- Detailed Proof-of-Concept (POC) exploits and remediation blueprints

### B. Mobile Application Security Testing (Android & iOS)
- Static Application Security Testing (SAST) & Dynamic Analysis (DAST)
- Insecure Data Storage, Keystore analysis, SSL Pinning bypass, Frida instrumentation
- Reverse engineering resistance, Code obfuscation assessment

### C. Network Infrastructure & Wireless Pentesting
- Internal & External Network Perimeter penetration testing
- Firewall rule review, Misconfigurations, Port forwarding, Default credentials
- Active Directory (AD) security audits, Kerberoasting, Pass-the-Hash defense validation
- Wi-Fi WPA2/WPA3 enterprise testing and rogue AP detection

### D. Cloud Infrastructure Security (AWS / Azure / GCP)
- Cloud Security Posture Management (CSPM)
- IAM roles, over-privileged policies, S3/Blob public leakage
- Container & Kubernetes cluster configuration reviews
